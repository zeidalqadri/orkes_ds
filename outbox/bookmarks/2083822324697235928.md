## Verdict: HIGH for sec- | MEDIUM for arbos-

### Why this matters

reverse-skill is a comprehensive skill router that teaches AI agents (Claude Code, Codex CLI, Cursor, Kiro, Cline) how to systematically approach reverse engineering, penetration testing, and security research. Instead of guessing commands, the agent follows a structured pipeline:

```
User task → RULES.md → MASTER-ROUTING (primary triage)
  → case-init / scope.md (auth + network profile; no ACT until ready)
  → Scenario skill → tools / MCP / scripts
  → timeline + Evidence→Finding→Path → report + field-journal
```

**Scope**: APK/Android, iOS, binary (IDA/radare2/Ghidra), .NET/C#, frontend JS/encrypted params, DSL VM, HTTP capture/replay, malware/YARA, pentest scanning, attack chain/red-team, CTF (40+ sub-skills), firmware/IoT, patch diff/N-day, pwn/exploit dev, EDR bypass, API/GraphQL, supply chain/SBOM, LLM/AI security, OLLVM deobfuscation, diagrams/reports.

**Key architectural patterns**:
1. **Scope gate before ACT**: case-init creates scope.md with auth + network profile before any target interaction — prevents accidental live-fire. Mirror of our PLAN→ACT pattern.
2. **Tool index auto-discovery**: Refresh scripts detect installed tools (jadx, apktool, Frida, IDA, etc.) and write to tool-index.md, so the agent knows what's available before executing.
3. **Evidence chain tracking**: Timeline → Evidence → Finding → Path format ensures reproducible, defensible analysis.
4. **Self-evolving knowledge base**: field-journal captures experience so the same mistakes aren't repeated.
