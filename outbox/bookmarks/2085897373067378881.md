## Relevance

### arbos-: MEDIUM

The quoted article’s visible title, **“AI Adoption is a Myth,”** directly challenges the failure mode relevant to the pm2 agent fleet: counting configured models, installed skills, or finished prose as success while workflows still stall, retry, need operator repair, or do not produce a reused artifact. ArbOS already has ingredients for this—`STATE.md`, goal outcomes, retry history, and watchdog signals—but they are not yet one adoption measure.

### sec-: HIGH

sec- has the sharper exposure because LLM work sits next to measurable production paths: document classification, WebDAV extraction, pricing enrichment, tender qualification, and model routing. A model is only adopted when it improves a bounded pipeline against its deterministic baseline without worsening cost, latency, false positives, or recovery burden. This matches existing concerns around provider failures, heavy enrichment, and resource pressure.

## Concrete Adopt / Adapt Proposals

1. **ADOPT: workflow-level adoption cards.** Before a new AI capability is promoted, record the workflow owner, input source, deterministic baseline, success metric, cost/latency ceiling, human correction path, rollback route, and a review date. “Model enabled” is not an outcome.

2. **ADAPT for arbos-: complete-goal telemetry.** Extend completion records with `verified_outcome`, elapsed time, retry/fallback count, token/provider cost estimate, and operator follow-up required. A recurring goal is adopted only if it lowers fresh-agent rediscovery or manual intervention across several runs—not merely because a report was produced.

3. **ADAPT for sec-: gate LLM stages with production comparators.** For each enrichment/extraction stage, retain a regex/rules/no-op baseline and log processed, accepted, empty, rejected, corrected, timeout, and fallback counts. Promote a model route only when it improves the target metric within defined resource limits; disable it automatically on sustained regression.

4. **DO NOT generalize from the article alone.** Run one instrumented pilot on a high-volume but reversible path—such as WebDAV document classification or supplier-enrichment triage—then decide from observed quality, throughput, and operator correction rate. Keep credentials, tender content, and state-changing remediation on deterministic controls.
