## Why

- The core problem matches arbos exactly: every loop step starts as a fresh agent and reconstructs context from `STATE.md`, `GOAL.md`, `INBOX.md`, expert notes, and `shared_learnings.md`.
- `brain.md` separates a current, rewritable decision truth from an append-only evidence timeline and writes the pair atomically. That is a useful improvement over undifferentiated accumulated notes.
- The repository is early (`v0.1.0`) and its “CLI-only writer” invariant is procedural: a normal editor can still alter Markdown. It also overlaps heavily with the existing control plane and existing memory-layering proposals.
- Its global setup rewires multiple agent configuration directories. That is unnecessary fleet-wide scope for a maintenance aid and risks conflicting instructions, duplicate sources of truth, and larger prompt loads.
- The included Node tests reported 10 passing subtests, but the test runner exited with code `134` in this environment. Treat the toolkit as a pilot dependency, not a baseline component.

## Concrete adopt/adapt proposals

1. **Adapt, do not install:** keep `STATE.md`/`GOAL.md`/`INBOX.md` as the live control plane. Add a small `context/decisions/` ledger only after a separate approved goal; it must not mirror task state or `shared_learnings.md`.
2. **Use a strict admission rule:** add a page only for a decision likely to matter in six months and hard to recover from code or git history (for example, SmartGEP auth architecture, portal tenancy boundaries, or model-routing policy).
3. **Use truth + evidence fields:** each decision record should contain `current_decision`, `rationale`, `affected_paths`, `owner`, and append-only dated evidence entries with source artifacts. Update the current decision and evidence together in one controlled helper.
4. **Pilot one sec- handoff:** migrate one recurring, high-cost context loss (SmartGEP authentication recovery) and measure whether the next fresh agent reaches a verified diagnosis faster. Retain only if it reduces repeated discovery without adding contradictory memory.
5. **Defer framework adoption:** do not run `brain.md`'s global `setup` or modify `AGENTS.md`/`CLAUDE.md` until the pilot proves value and a single owner/source-of-truth boundary is specified.
